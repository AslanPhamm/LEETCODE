# LEETCODE & Learning Journey

Welcome to my repository! This is a centralized space where I document my daily coding practice, bioinformatic tool automation, and language learning progress. 

---

## **📂 Repository Structure**

The repository is organized into three main focuses:

```text
.
├── Bash/               # Solutions to bioinformatics challenges on rosalind.info
├── Python_Basic/       # Core Python foundational tracks tailored for Data Science & Statistics
└── English/            # Notes, vocabulary, and materials for technical language practice
```

### **🧬 1. Rosalind Bioinformatics Challenges (Bash)**
This directory contains my shell scripts and pipeline solutions for Rosalind, a platform for learning bioinformatics through problem-solving.

- Focus: Automating text processing, handling FASTA/FASTQ sequence data, utilizing core CLI utilities (awk, sed, grep), and building parallelized bioinformatic loops.

- Goal: Master Linux-based high-throughput data manipulation essential for real-world genomic workflows.

### **📊 2. Python Basics for Data Science & Statistics**
Here, I am designing structured, foundational Python lessons. Rather than just generic programming, this track is heavily tailored toward data science, analytics, and statistical computing workflows.


- Data Science Orientation: Implementing numeric arrays, matrix manipulation logic, matrix string extraction, mathematical algorithms, and parsing structured tabular/CSV logs natively.


- Purpose: Creating clean, reusable code templates that serve as a learning reference for core analytical logic before scaling up to complex scientific packages (like NumPy, Pandas, or SciPy).

### **🇬🇧 3. English Studies**
A dedicated space to track my English learning progress.

- Content: Vocabulary logs, grammar reviews, technical terminology relevant to science and engineering, and writing exercises.

- Purpose: Continuously improving my communication skills to effectively navigate international technical documentation and collaborate globally.
